**Student:** how to open claude in vs code

**Claude:** There are two ways to use Claude Code in VS Code:

**Option 1: The extension (recommended)**
1. In VS Code, open Extensions (`Ctrl+Shift+X`).
2. Search for **"Claude Code"** (published by Anthropic) and click Install.
3. Open it in one of these ways:
   - Click the **Claude (spark) icon** in the top-right editor toolbar or in the sidebar.
   - Or press `Ctrl+Shift+P` and run **"Claude Code: Open"**.
4. Sign in when it asks.

**Option 2: The CLI in VS Code's terminal**
1. Open the integrated terminal (`` Ctrl+` ``).
2. `cd` to your project, for example `cd C:\Users\clari\minipill-model`.
3. Run `claude`.

When you run `claude` this way, it usually installs the extension for you too. After that, `Ctrl+Esc` opens Claude Code, and it can see your open files and selection.

**Tip:** To open this project directly, run `code C:\Users\clari\minipill-model` from any terminal. Then open Claude Code inside VS Code, and it will work in that folder.

**Claude:** You don't need to set anything up. VS Code sessions will save to the same journal, as long as you open the **minipill-model folder** in VS Code.

**Why it works:**
- The journal hook is set in the project's own settings file, `.claude/settings.json`, so it isn't tied to the terminal. It runs at the start and end of every Claude Code session in this folder, and the VS Code extension counts.
- The extension stores its session logs in the same place as the terminal: `~/.claude/projects/C--Users-clari-minipill-model/`. The hook script copies from there into `journal/` and `journal/readable/`.
- Your script's notes also say git runs it before every commit, so a commit catches anything that's been missed.

**One thing to watch:** open the project folder itself, using **File → Open Folder → `C:\Users\clari\minipill-model`** or `code C:\Users\clari\minipill-model`. If you open a parent folder like `C:\Users\clari`, Claude won't load this project's settings, so the hook won't run and the session will be logged somewhere else.

**To check it worked:** after your first VS Code session, look for a new `.jsonl` file in `journal/` and a matching `.md` in `journal/readable/`.
