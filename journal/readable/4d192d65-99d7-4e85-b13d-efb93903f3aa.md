If you're inside an `except` block, use `logger.exception` instead. It logs at error level and includes the full traceback:

```python
try:
    sol = solve_ivp(rhs, t_span, y0)

    raise   # re-raise unless you can really recover
```

Some tips:
- **Call `basicConfig` only once**, at the entry point (your app or a script), not inside `src/` modules. In those modules, just use `logger = logging.getLogger(__name__)`.
- **Use `%s` placeholders, not f-strings.** The message is then only built if it actually gets logged.
- **To also save logs to a file**, add `filename="run.log"` to `basicConfig`.
- **Use `logger.warning(...)` for problems the model can live with.** For example, a mass-balance check that's off by a small tolerance.
